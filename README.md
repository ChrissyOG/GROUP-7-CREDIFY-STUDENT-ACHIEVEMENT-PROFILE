# Credify Student Achievement Profile

Credify is a student achievement profile project intended to present student achievements and supporting evidence. The HTML/CSS interface is being prepared for integration with the project's other application modules and backend; the complete app requires those additional files as they are integrated.

## Setup prerequisites

- Git, to obtain and work with the project repository.
- A modern web browser to view the interface.
- The remaining application modules and backend files/configuration will be needed to run the complete integrated app.
