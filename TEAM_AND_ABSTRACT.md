## Abstract

Credify is a digital student achievement profile that helps students record accomplishments, submit supporting evidence, and request verification or recommendations. Lecturers can review and endorse achievement claims and prepare recommendation letters. The application stores profile and request data using Supabase and supports email alerts for lecturer requests through a Supabase Edge Function. By bringing student records, evidence, and lecturer endorsements together, Credify aims to make achievements easier to manage and share.
